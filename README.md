# 资金台账 AI 自动化系统

> 一个面向会计/财务场景的「多银行账户资金台账自动化」项目，覆盖从原始流水到标准台账、报表、预警与可视化的完整流水线。
> 技术形态：**Python + Excel(WPS) 自动化**，零前端、零部署，适合直接写进简历并现场演示。

## 一、项目背景

企业出纳/会计往往面对多家银行、多种格式的流水 CSV，手工整理成统一资金台账、复核异常，耗时且易错。
本项目用 Python 把这条链路自动化：**多源流水 → 清洗 → 智能分类入账 → 日报/月报 → 异常预警 → 可视化看板 → 输出 Excel**，
把原本数小时的月度对账压缩到「一键运行」。

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| 多源流水自动清洗 | 兼容工行/招行/建行等不同列名、日期格式（`2026/01/05`、`2026年1月5日`）、金额格式（`1,234.50`、`¥1,234.50`） |
| 智能分类入账 | 基于「关键词 + 规则」引擎，把摘要/对方户名映射到会计科目，输出借贷方向与置信度（可平滑扩展为 LLM 接口） |
| 资金日报 / 月报 | 按日/月自动聚合收入、支出、笔数、净流量、期末余额 |
| 异常与风险预警 | 识别大额支出、借贷不平、疑似重复交易、非工作日交易，并标注风险等级 |
| 可视化看板 | 自动生成月度收支趋势图与支出结构饼图，嵌入 Excel |

## 三、技术架构

```
银行CSV(多账户/多格式)
        │  data_cleaner.py   统一字段、解析日期/金额
        ▼
  标准流水 DataFrame
        │  classifier.py     关键词规则引擎 → 会计科目 + 借贷方向 + 置信度
        ▼
  标准资金台账
        ├─ reporter.py      日报 / 月报聚合
        ├─ anomaly.py       异常风险扫描
        └─ visualizer.py    趋势图 / 饼图
        ▼
  Excel 多 Sheet 交付（openpyxl 美化 + 图表嵌入）
```

## 五、使用方法

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 生成脱敏模拟数据（首次运行或重置数据时）
python src/generate_sample_data.py

# 3. 运行主程序，生成资金台账 Excel
python src/main.py

# 4. 打开 output/资金台账_2026.xlsx
```
